# Active Backlog

The active backlog is organized by bounded item under this directory.

| Area | Location |
|---|---|
| Product and engineering backlog items | `BL-NNN-<slug>/` |
| Reusable item template | [`_TEMPLATE/`](./_TEMPLATE/) |
| Mobile phase tasks | [`../tasks/mobile/README.md`](../tasks/mobile/README.md) |
| Backend phase tasks | [`../tasks/backend/README.md`](../tasks/backend/README.md) |

Superseded dating APRDs are retained under
[`../archive/legacy/specs/`](../archive/legacy/specs/). They are historical
references and are not active product requirements.
