# Definition of Done (DoD) & Verification Gates

Every task, vertical slice, or pull request generated by an AI coding agent must satisfy this automated and structural Definition of Done before being marked complete.

---

## 1. Architectural Compliance Checklist

- [ ] **Feature-First Confinement**: All code related to the feature resides inside `lib/features/<feature_name>/` (or `backend/app/api/v1/endpoints/` for mock routes).
- [ ] **Unidirectional Flow**:
  - Widgets observe ViewModel providers only.
  - ViewModels communicate only with abstract Repository interfaces.
  - Zero direct API calls, storage access, or raw JSON parsing inside UI widgets.
- [ ] **Zero Platform Leakage in Widgets**:
  - No `Platform.isAndroid`, `Platform.isIOS`, or `Platform.isWindows` calls in widget files.
  - Responsive adaptation is achieved exclusively via `LayoutBuilder`, `MediaQuery`, or constraint breakpoints.
- [ ] **Anti-Scope Adherence**: None of the forbidden capabilities listed in the task's Anti-Scope have been implemented.
- [ ] **Ubiquitous Language**: Entity names adhere strictly to the active
  [terminology policy](../../../policies/product/terminology.md).

---

## 2. Automated Verification Commands

Run and verify success for the relevant toolchains:

### Frontend (Flutter)
```bash
# 1. Format code
dart format --output=none --set-exit-if-changed .

# 2. Static analysis with zero warnings/errors
flutter analyze

# 3. Unit and Widget test suites
flutter test
```

### Backend (Python / FastAPI with `uv`)
```bash
cd backend

# 1. Dependency sync check
uv sync --extra dev

# 2. Pytest suite
uv run pytest
```

---

## 3. Test Coverage Requirements

- **Domain Entities**: Unit tests verify equality (`operator ==`), `hashCode`, `copyWith`, and serialization.
- **Repositories**: Unit tests verify mock success, empty return, error throwing, and mutation tracking.
- **ViewModels**: Unit tests verify all states (`initial`, `loading`, `loaded`, `empty`, `error`), transitions, and retry behavior.
- **Widgets**:
  - Widget tests verify rendering for all status states.
  - Widget tests verify adaptive responsive layouts (Mobile `< 800px` and Desktop `$\ge 800px$`).

---

## 4. Security & Cleanliness Gates

- [ ] Zero secrets, tokens, passwords, or personal test data committed.
- [ ] No extraneous unapproved packages added to `pubspec.yaml` or `pyproject.toml`.
- [ ] No temporary debug scripts, scratch files, or comment noise left behind.
